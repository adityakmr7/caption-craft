🔄 How the System Works
plain

2. Browser extracts audio via FFmpeg WASM
3. Browser sends audio + style choice to API
4. API checks credits (atomic transaction)
5. API stores raw video in Cloudflare R2
6. API creates DB record → status: PROCESSING
7. API enqueues job via Inngest
8. Worker calls OpenAI Whisper → gets transcript
9. Worker formats captions (style, timing, animation)
10. Worker runs FFmpeg → burns captions into video
11. Worker uploads finished video to R2
12. Worker updates DB → status: COMPLETED
13. Worker sends email → "Your video is ready!"
14. User downloads → posts to TikTok/Reels/Shorts
