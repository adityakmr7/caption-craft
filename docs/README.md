# CaptionCraft — Pivot Docs

CaptionCraft is pivoting from a generic screenshot-captioning tool into a **LinkedIn content generator for Indian bootstrapped founders documenting their build-in-public journey**.

This directory is the source of truth for that pivot. Start here, then go deeper:

| Doc | What's in it |
|---|---|
| [PRD.md](./PRD.md) | Product requirements — problem, ICP, positioning, features, requirements, metrics |
| [ROADMAP.md](./ROADMAP.md) | Phased build plan, from MVP to differentiation moat |
| [COMPETITORS.md](./COMPETITORS.md) | Competitive landscape — direct, adjacent, and the "do nothing" alternative |
| [MARKET-RESEARCH.md](./MARKET-RESEARCH.md) | Demand signals, pricing benchmarks, unit economics, sources |

## One-line summary

> Upload a screenshot of your product, milestone, or metric → get 3 ready-to-post LinkedIn variations with hashtags, in a voice that sounds like an Indian founder, not a San Francisco AI tool.

## Status

Pre-build. Landing page + waitlist exist (`app/`); no generation logic exists yet. See [ROADMAP.md](./ROADMAP.md) for what ships next.
